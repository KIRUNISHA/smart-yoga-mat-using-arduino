# Smart Yoga Mat Using Arduino

## Project Overview

The Smart Yoga Mat is an Arduino-based health monitoring system designed to enhance user safety and awareness during yoga and fitness exercises.

The system uses a HW-827 heart rate sensor and an LM35 temperature sensor to continuously monitor physiological parameters such as heart rate and body temperature.

The collected data can be displayed in real time using an OLED/LCD display or Serial Monitor.

The main goal of this project is to provide an affordable, portable, and user-friendly solution for health monitoring during yoga and fitness activities.

## Objectives

- To develop a smart yoga mat using Arduino.
- To monitor heart rate during yoga and fitness exercises.
- To monitor body temperature in real time.
- To provide real-time health data to the user.
- To improve awareness of physiological conditions during exercise.
- To reduce the risk of unnoticed overexertion.
- To develop an affordable and portable monitoring system.

## Problem Statement

Traditional yoga mats do not provide any feedback about the user's physiological condition during exercise.

Without real-time monitoring, users may not notice excessive exertion, changes in body temperature, or other health-related conditions.

Therefore, there is a need for a smart and accessible system that can provide real-time health monitoring during activities such as yoga.

## Proposed Solution

The proposed system integrates health monitoring sensors directly with a yoga mat using an Arduino microcontroller.

The system uses:

- HW-827 Heart Rate Sensor
- LM35 Temperature Sensor
- Arduino Microcontroller
- OLED/LCD Display

The sensors collect real-time physiological data, and Arduino processes the sensor readings and displays the information to the user.

## Working Principle

The system works by continuously monitoring the user's heart rate and body temperature during yoga exercises.

1. The user performs yoga exercises on the smart mat.
2. The HW-827 sensor collects heart rate information.
3. The LM35 sensor measures temperature.
4. The sensors send the collected data to the Arduino.
5. Arduino processes the sensor readings.
6. The processed information is displayed on an OLED/LCD display or Serial Monitor.
7. The user can observe the real-time physiological data.
